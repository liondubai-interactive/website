# LionDubai Interactive website

Public product, privacy, terms, and contact site for LionDubai Interactive.

## Local development

Requires Node.js 22.13 or newer.

```powershell
npm ci
npm run dev
```

The local page is served below the same repository path used in production:

```text
http://localhost:3000/website/
```

Validate the complete static export with:

```powershell
npm test
```

The site is intentionally informational. It has no analytics, advertising,
forms, account database, or application secrets.
